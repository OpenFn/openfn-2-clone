# Notes

A dumping ground for principles in progress: rough thinking, questions, things brought in from elsewhere. Any file, any shape.

Nothing here is a rule. This branch is the source of truth: a note becomes a rule only when it's settled and moved into PRINCIPLES.md in Lucy's words, and then it's deleted from here. Something from openfn-3-poc main or another repo comes in only when it's needed, and only the parts we still agree with.
