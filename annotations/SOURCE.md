# Where this folder comes from

The current annotations live in OpenFn/lightning on branch
`experiment/overnight-1`, in `annotations/`. Edit them there, not here.

This folder is a copy, taken from branch `claude/tender-mendel-0pejfc` at
commit `4ccd077` ("Rate shared annotations, restore a dropped flow heading,
summarise ratings in the report"), so the two may differ.

The demo's annotations panel reads these files at build time. To update them,
replace this folder with `experiment/overnight-1`'s `annotations/` and update
the branch and commit above.
